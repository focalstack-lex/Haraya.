## Mobile tab bar redesigned as a notched dock

- `BottomTabBar` is now a floating dock: mascot ink bar (`--ios-dock` #1D1203), 64px tall, 22px radius, inset 12px.
  The active icon lifts into a 48px steam puck (`--ios-dock-accent` #E7AC67) that sits in a notch carved from the
  bar with a CSS mask (content shows through). Puck, notch and icon share one axis via container query units
  (`.dock` in `src/index.css`) and slide on `--ios-ease`. Labels, `data-tour` targets, `aria-current`, the saved
  badge and the hide-while-modal rule are unchanged. Geometry is in px because the project scales Tailwind
  spacing (`--spacing: 0.225rem`), which first rendered the dock at 50px and misaligned the puck. Tab row is
  inset 10px so the end-tab notch never crosses the rounded corner (seen at 320px). Bottom spacer in `App.tsx`
