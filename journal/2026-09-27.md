## [2026-09-27] Session Log: Greenfield Scaffold and Full Platform Build

### Architectural Decisions

- Initialized the repository at `C:\Users\User\Pictures\Haraya` with Vite + React 19 + TypeScript, mirroring the Habi sibling's runtime so the two platforms share identical behavior and the ecosystem bridge stays symmetrical. The blueprint's React 18 baseline is satisfied by React 19 (same hooks surface, `useSyncExternalStore` included); decision recorded in README.
- Design system rebuilt in `src/index.css` as a cream-obsidian-coffee token layer: Tailwind v4 with the zinc scale remapped to the Haraya palette (canvas `#FBF4E4`, card `#FFF9E9`, subsurface `#F3ECD8`, obsidian `#1A2225`, hairline `#E6DCC0`, muted `#55615D`, roast accent `#C86428`), Cooper/Fraunces display serif, Plus Jakarta Sans body, Habi's density scale (15px root, tighter mobile step), safe-area utilities, and no dark mode (blueprint defines a cream-only palette).
- State architecture: reactive subscriber services (`catalogService`, `userPrefsService`, `communityService`, `authService`, `roasterService`) with localStorage merge over the mock seed and version counters consumed via `useSyncExternalStore` hooks in `src/hooks/useServiceVersions.ts`.
- Routing: hash router (`src/utils/router.ts`) with `#/tab/:id`, `#/cafe/:id`, `#/bean/:id`, `#/roastery/:handle`, `#/drop/:id`, and shareable `#/list/:slug?name=&cafes=&beans=` deep links.
- Ecosystem bridge: Habi switcher in the header and footer, target URL isolated in `src/config/ecosystem.ts` (single documented integration point).
- Roaster flow: three-step verified sign-up (business, DTI/Mayor permit + ID documents as dataURLs, account) -> pending -> admin Control Room approval -> auto-created cafe storefront profile. Browser-mock auth boundary is documented as demo-only per the Security-First Deployment Gate.
- Zero-emoji, zero-em-dash, anti-eyebrow-pill, and 2-row control directives enforced across all UI copy; lucide-react plus a custom Haraya SVG icon set only.
- `docs/CODE_MAP.md` generated by the committed `scripts/generate-code-map.mjs` (extended from the project-scaffolding reference to index `.ts`/`.tsx`), wired as `map:code` / `map:code:check` npm scripts.
